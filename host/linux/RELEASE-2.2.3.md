## Español

Versión preliminar de Linux x86-64 con selector **Español / English**, tema oscuro basado en Windows y panel de botones, sticks y batería. Requiere el receptor oficial **WUP Stream**.

- El **AppImage** se extrae y abre automáticamente, sin FUSE. Dale permiso de ejecución antes de abrirlo.
- El **.deb** instala sus dependencias con APT. Para usar el mando virtual con el AppImage, comprueba que tu sesión tenga acceso a `/dev/uinput`.

[Guía y requisitos en español](https://github.com/JLiveOf/Generic-Wupstream-Program/blob/v2.2.3-linux.1/host/linux/README.md)

## English

Linux x86-64 prerelease with a **Spanish / English** selector, a dark Windows-inspired layout, and a live panel for buttons, sticks, and battery status. It requires the official **WUP Stream** receiver.

- The **AppImage** extracts itself on launch and runs without FUSE. Mark it executable before opening it.
- APT installs the **.deb** dependencies. For virtual controller support with the AppImage, check that your session can write to `/dev/uinput`.

[English guide and requirements](https://github.com/JLiveOf/Generic-Wupstream-Program/blob/v2.2.3-linux.1/host/linux/README.en.md)
